# assets/

Supplementary files that ship inside the `.s9pk` alongside compiled package
code. The directory is currently a required placeholder.

Future assets may include:

- entrypoint or wrapper scripts the daemon execs,
- configuration templates / generators,
- static files (default configs, seed data, certificates),
- an `ABOUT.md` or other docs you want bundled.

This directory must not be empty. Keep this README until a runtime asset
replaces it.
